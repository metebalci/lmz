LMZ

MIT’s Lisp Machine, usable today: on current hardware, with current displays and networks, and with today’s tools and practices.

System 1001 GitHub
What it is
  • MIT’s Lisp Machine system for the CADR, forked from System 100: MIT’s System 99.32, recovered from its backup tapes and brought up by LM-3.
  • LMZ System 1001 is out: a cleaner system with unattended cold loading. Get the disk pack and sources.
  • It runs on muir, the software simulator, and muir-fpga, on an FPGA, with ozd as its Chaosnet services daemon.
  • The source is at github.com/metebalci/lmz, under the AGPL, version 3 or later.
