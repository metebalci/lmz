LMZ

MIT’s Lisp Machine, usable today: on current hardware, with current displays and networks, and developed the way software is developed now.

Release 1000 GitHub
What it is
  • The system of MIT’s CADR, carried on. LMZ is forked from System 100: MIT’s System 99.32, recovered from its backup tapes and brought up by LM-3.
  • Release 1000 is out: a disk pack ready to boot, and the sources. Get it on GitHub.
  • It runs on muir, the software simulator, and muir-fpga, on an FPGA, with ozd as its Chaosnet services daemon.
  • The source is at github.com/metebalci/lmz, under the AGPL, version 3 or later.
